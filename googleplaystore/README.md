# Google Play Store Dataset - EDA + Encoding

## Project Overview

This project focuses on Exploratory Data Analysis (EDA) and Categorical Encoding using the Google Play Store dataset.
The goal is to explore app trends, understand user review patterns, and prepare the data for future modeling.

## Dataset

Kaggle - Google Play Store Apps dataset (googleplaystore.csv, googleplaystore_user_reviews.csv).
The dataset is not included in this repository.
You can download it from:
https://www.kaggle.com/datasets/lava18/google-play-store-apps

## Analysis Includes

- Dataset overview and structure
- Missing value and data cleaning analysis
- Distribution of app categories, ratings, and installs
- User review sentiment exploration
- Categorical encoding strategies

## Purpose of This Project

- Practice real-world data cleaning on messy data

- Understand categorical and text feature encoding

- Explore multi-file dataset joining and analysis

- Prepare data for future classification or regression models
